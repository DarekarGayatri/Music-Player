# Music World Web Application

## Description
The **Music World** web application is a simple and interactive music player designed to play a curated selection of copyright-free songs. Built using HTML, CSS, and JavaScript, this application features a clean and responsive user interface that enhances the listening experience.

### Key Components:
- **HTML Structure**: The application consists of a navigation bar with links to "Home" and "About," a song list displaying cover images, song names, and play buttons, and playback controls at the bottom for easy navigation.
  
- **CSS Styling**: The CSS file provides a dark theme with a visually appealing layout, utilizing Flexbox for alignment and spacing. It also includes custom fonts and background images to enhance aesthetics.

- **JavaScript Functionality**: The JavaScript code manages audio playback, including play/pause functionality, song selection, volume control, and progress tracking. It dynamically updates the UI based on user interactions, such as clicking play buttons or adjusting the volume slider.

### Features:
- **Song List**: Displays a list of songs with cover images, names, and durations.
- **Playback Controls**: Users can play, pause, skip forward, and skip backward through the songs.
- **Volume Control**: A slider allows users to adjust the volume, with mute functionality available.
- **Progress Bar**: Indicates the current playback position of the song.

### Usage:
To use the application, clone the repository, open `index.html` in a web browser, and enjoy the music. Ensure that the audio files referenced in the JavaScript are available in the same directory.

This project serves as a demonstration of fundamental web development skills and can be further enhanced with additional features like playlists and search functionality.
